# “我的”页紧凑列表布局设计

## 背景

当前 `fragment_user.xml` 使用“头像信息区 + 单个 2×2 大卡片”。页面只有四个入口，卡片却占用较大高度，图标与文字分散，导致内容重心集中在上半屏且层级偏弱。

本次只优化现有内容的布局，不新增统计、最近观看或其他数据模块，也不改变任何业务行为。

## 目标

- 让用户信息与功能入口形成清晰的两级结构。
- 提高四个入口的可扫描性与整行点击效率。
- 保持深色主题、极光蓝品牌色和现有导航风格一致。
- 保留合理留白，不用无实际内容的装饰填满页面。

## 页面结构

页面继续使用可滚动的单列容器，由以下两部分组成：

1. 个人信息头：`64dp` 圆形头像，右侧显示用户名和“欢迎回来”。头像保留点击更换功能。
2. 我的服务：小型分区标题，以及一张容纳四行菜单的圆角卡片。

四行菜单按现有顺序排列：

1. 播放记录
2. 我的追番
3. 离线缓存
4. 设置

## 菜单行设计

- 每行最小高度为 `64dp`，整行均可点击。
- 左侧为 `36dp` 的浅品牌色图标底座，内部沿用现有矢量图标。
- 中间为功能名称，使用主文本色。
- 右侧增加低强调度的箭头，明确可进入下级页面。
- 相邻行使用细分割线区分，最后一行不显示底部分割线。
- 点击继续使用 Material 水波纹反馈。

卡片采用现有深色表面色、软边框和 `16dp` 圆角，不增加阴影或新的视觉主题。

## 行为与代码范围

- 保留 `btn_history`、`btn_star`、`btn_download`、`btn_settings` 和 `avatar_file` 的 ID。
- 保留 `UserFragment` 现有监听器、跳转、头像加载及上传逻辑。
- 主要修改 `app/src/main/res/layout/fragment_user.xml`。
- 如布局需要，仅新增用于图标底座、分割线或箭头的最小资源；优先复用现有颜色、样式与图标。
- 不重构无关 Java 代码，不调整底部导航栏，不改其他页面。

## 适配与无障碍

- 用户名保持单行省略，避免长名称挤压布局。
- 入口保留明确的 `contentDescription` 或可由整行文本表达的语义。
- 使用 `dp`/`sp` 和 `match_parent`，保证常见手机宽度下不横向溢出。
- `ScrollView` 保留，以兼容小屏和系统字体放大。

## 验证标准

- Android 资源与应用模块能够成功编译。
- 四个菜单入口仍跳转到原有页面。
- 点击头像仍能打开图片选择器。
- 长用户名、常见屏幕宽度及字体缩放下无重叠或裁切。
- 页面只包含已确认的个人信息和四个现有入口。
